ABOUT ME

Halo, perkenalkan nama saya Revan Falah. Saya adalah mahasiswa Program Studi Sistem Informasi yang sedang mempelajari berbagai hal mengenai teknologi informasi dan pengembangan website.

Website ini dibuat sebagai salah satu tugas dalam mata kuliah Pemrograman Web. Dalam pembuatan website ini saya menggunakan HTML dan Visual Studio Code.

💻 Tentang Saya

Saya memiliki ketertarikan pada dunia teknologi dan komputer. Saya senang mempelajari hal-hal baru yang berkaitan dengan website, pemrograman, dan teknologi informasi.

Saya percaya bahwa kemampuan dapat berkembang dengan terus belajar, mencoba, dan tidak takut melakukan kesalahan. Oleh karena itu, saya terus berusaha meningkatkan pengetahuan dan keterampilan saya di bidang teknologi informasi.

🎯 Tujuan

Tujuan saya adalah dapat memahami pemrograman dengan lebih baik, membuat website yang menarik dan bermanfaat, serta mengembangkan kemampuan di bidang teknologi informasi untuk masa depan.

“Terus belajar, terus mencoba, dan jangan takut untuk berkembang.”

TUTORIAL MEMBUAT WEBSITE

Pada halaman ini saya akan menjelaskan tutorial sederhana dalam membuat website menggunakan HTML dan Visual Studio Code. HTML digunakan untuk membuat struktur sebuah halaman website, sedangkan Visual Studio Code digunakan untuk menulis dan mengedit kode program.

1. Membuka Visual Studio Code

Langkah pertama adalah membuka aplikasi Visual Studio Code pada komputer. Setelah aplikasi terbuka, kita dapat membuat folder baru untuk menyimpan seluruh file website yang akan dibuat.

2. Membuat File HTML

Setelah membuat folder project, buat file baru dengan nama index.html. File HTML merupakan file utama yang digunakan untuk membuat halaman website. 

<!DOCTYPE html>
<html>
<head>
    <title>Website Saya</title>
</head>

<body>

    <h1>Selamat Datang</h1>

    <p>Ini adalah website saya.</p>

</body>
</html>

3. Menambahkan Judul

Untuk membuat judul pada halaman website, kita dapat menggunakan tag <h1> sampai <h6>. Semakin besar angka yang digunakan, ukuran judul akan semakin kecil. 

<h1>Website Profil Revan</h1>
<h2>Tentang Saya</h2>
<h3>Data Diri</h3>

4. Menambahkan Paragraf

Tag <p> digunakan untuk membuat paragraf. Dengan tag ini, kita dapat menampilkan informasi atau tulisan pada halaman website. 

<p align="justify">
    Selamat datang di website profil saya.
    Website ini dibuat menggunakan HTML.
</p>

5. Menambahkan Gambar

Untuk menampilkan gambar pada website, gunakan tag <img>. Pastikan lokasi gambar sesuai dengan folder yang terdapat di dalam project. 

<img src="gambar/foto.jpg" width="300" alt="Foto Saya">

6. Membuat Link Antar Halaman

Tag <a> digunakan untuk membuat link yang dapat menghubungkan halaman satu dengan halaman lainnya. 

<a href="profil.html">Profile</a>
<a href="gallery.html">Gallery</a>
<a href="guestbook.html">GuestBook</a>

7. Menyimpan dan Menjalankan Website

Setelah selesai menulis kode, tekan Ctrl + S untuk menyimpan file. Kemudian buka file HTML menggunakan browser seperti Google Chrome atau Microsoft Edge untuk melihat hasil website.

Selamat mencoba membuat website dengan Visual Studio Code!
